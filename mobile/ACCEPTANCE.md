# 真机验收表（闸门 C）

`mobile/tools/gate-a.sh` 与 `gate-b.sh` 只能证明**包**是对的：结构、字体覆盖、签名、对齐。
它们证明不了这个包在一台真实手机的 OEM 系统上会不会豆腐、能不能读到蓝牙手柄的原始轴。

这一页就是那部分。**它是唯一允许宣布「真机通过」的地方**，而且必须由人填。

## 第 0 节 前置条件（不满足就不许打勾）

四项全部为「是」之前，下面任何一格都不许勾。

- [ ] **设备状态可被检查**：`bash mobile/tools/doctor.sh device` 退出码为 0，且输出里有一行
      以 `✓ device` 开头。它不是构建闸门的一部分（导出不需要手机），只在这一节被点名运行。
- [ ] **两台不同 OEM 的手机**：不是两台同品牌同型号，也不是同一台刷了两次。
      分别记录厂商与型号：

      adb shell getprop ro.product.manufacturer
      adb shell getprop ro.product.model
      adb shell getprop ro.build.version.release

- [ ] **一只真手柄**：Xbox 或 DualSense，能与手机完成蓝牙配对（在系统蓝牙设置里能看到已连接）。
- [ ] **一条明确禁令**：**模拟器不算**，**单台手机不算**，**「上次装过所以肯定没问题」也不算**。
      这三件事都出现过，而且都能让一张表看起来填满、实际什么也没证明。

### 输入事件日志（04-10 引入，APK 27,071,318 B 及之后的包都包含）

04-10 加了一件事：**测试者按下的每一个键边沿、每根轴的有效变化都会被写进手机上的一个文本文件**，
同时镜像到 logcat。不需要实时截图，也不需要 `run-as`（release 包不可调试）。04-11 的包
（27,079,510 B）沿用同一套日志，D0 操作按上面「D0 操作说明（04-11）」执行；日志只是多了一条
事后可回放的证据通道。

读取方式（两条通道内容相同，第一条是主通道）：

    adb exec-out cat /sdcard/Android/data/com.fifaskill.trainer/files/input_log.txt
    adb logcat -s godot:I | grep INPUT_EVT

第二条命令必须过滤 `godot` 标签：Godot 的 `print` 统一走这个标签，`INPUT_EVT` 是消息前缀，
**不是** logcat 标签 —— 写成 `adb logcat -s INPUT_EVT` 会一行也看不到。

日志字段（三种行，全部是 ASCII）：

| 行形状 | 含义 |
|--------|------|
| `# session v=<version> t=<ms> mono` | 会话头：每次启动一行，用于把日志按进程分段 |
| `t=<ms> dev=<d> btn=<i> name=<canonical> down=<0\|1>` | 按键边沿：毫秒时间戳、设备号、按钮索引、规范名（A/B/X/Y/LB/RB/DPAD_*）、按下 1 / 松开 0 |
| `t=<ms> dev=<d> axis=<i> v=<x.xxx>` | 轴值：毫秒时间戳、设备号、轴索引、原始值（三位小数） |

判读规则：

- **时间戳**来自单调时钟，同一次运行内只增不减；进程重启后从会话头重新开始。
- **按钮边沿永不节流**：按下与松开各一行，可以直接数「按了几次」。
- **轴有节流**：同一根轴 `|Δ| < 0.02` 且距上次写入 `< 16 ms` 时跳过；静置时每 16 ms 一行心跳。
  快速搓动时每一帧都可能留下一条，慢推时只保留有效变化。
- **2 MB 自动轮转**：超过阈值后前半段写入 `input_log.1.txt`，主文件保留后半段。
  长时间测试不需要手动清空，只会丢最旧的一半。
- **隐私边界**：日志只有上表三种行；**不写**设备序列号、账号、配置文件内容或任何用户数据。
- **失败不影响输入**：任何写入错误只在 logcat 打一行 `INPUT_LOG_ERROR ...`，之后本次运行不再重试；
  手柄输入、判定与界面都不受影响。

验收时把这两条命令的输出整段贴进证据格即可（不需要逐行转述）：

    adb exec-out cat /sdcard/Android/data/com.fifaskill.trainer/files/input_log.txt
    adb shell wc -c /sdcard/Android/data/com.fifaskill.trainer/files/input_log.txt
