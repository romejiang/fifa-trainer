    - `static func evaluate_step(samples: Array[PackedFloat32Array], rest: PackedFloat32Array) -> Dictionary`：返回 `{ok, axis, sign, delta, samples, margin, separation, code, message}`。
      契约写明「`samples` 是调用方已经切好的 300 ms 窗口；本函数不做滑窗」。算法：`delta[i] = mean(window[i]) - rest[i]`；`w = argmax |delta[i]|`；`samples` 返回窗口长度；**`delta` 返回有符号的 `delta[w]`**（`sign` 由它导出；质量记录与排障读它，不重新算一遍）；`margin = |delta[w]| - max(|delta[others]|)`（单轴数据时取 `|delta[w]|`）；`separation = |delta[w]| / max(|delta[second]|, 1e-6)`。
      拒绝顺序（先到先拒，原因必须具体）：`samples < MIN_SAMPLES` → `not_enough_samples`；`|delta[w]| < MIN_DELTA` → `not_enough_travel`；`margin < MIN_MARGIN` → `ambiguous_axes`。通过时 `ok = true`、`axis = w`、`sign = 1 if delta[w] > 0 else -1`、`code = &""`。
      中文 message 必须含实际值，例如「位移不够：最大只有 %.3f（至少要 0.5）」「两轴同时动了：margin %.3f < 0.25，请只推一个方向」。
