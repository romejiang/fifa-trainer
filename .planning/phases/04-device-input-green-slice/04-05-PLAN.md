<objective>
让一台全新手机第一次打开应用时，用户只看屏幕就能走完「配对 → 按任意键唤醒 → 四步轴探测 → 中点 + 满量程校准 → 布局确认」，并在确认之前**进不去**练习。

Purpose: 成功标准 2 的原话是「全程不读文档」。这意味着引导必须把「为什么」也说清楚（安卓蓝牙手柄在收到第一次输入前不出现在设备列表里；校准要双手离开摇杆），并且每一步的失败都要给出具体原因而不是「重试」。同时成功标准 4 要求「必须用户按键确认后才进入练习」——本计划把这条做成状态机的不变量，界面只是渲染器。

Output: 一个纯状态机 `OnboardingFlow`（无头可测）、组合根 `main.gd` / `main.tscn`、引导屏 `onboarding_screen.gd` / `.tscn`、`project.godot` 的新主场景与显示设置、以及字体闭世界（`CHAR_SOURCES` 登记 + 机械断言）。

## 这一波的形状

先做**纯状态机并证明**（Task 1），再做**渲染器**（Task 2），最后**把字形闸门的闭世界缺口补上**（Task 3）。顺序不能反：如果先做界面，状态机会长在 `_process` 里，就再也无法在无头环境里证明「不触摸也能走完」。

## 明确不做

- 不做自动推进 / 组进度点 / 音效 / 轨迹绘制（Phase 6 / 7）。
- 不做断连重连的完整 UX（Phase 8）；本阶段只做「检测到断开 → device_lost」的最小行为。
- 不做 badge / 动画 / 主题系统；字号常量足够。
- 不做多设备选择 UI：`get_connected_joypads()` 返回多台时只取第一台并把设备名显示出来（完整选择归 Phase 8）。
</objective>
