<objective>
给输入层加一个「事后可读」的事件日志：每次按键、每根轴的有效变化，带毫秒时间戳写到 `/sdcard/Android/data/com.fifaskill.trainer/files/input_log.txt`，同时打 logcat `INPUT_EVT`。测试者按完任意组合后，执行 `adb exec-out cat /sdcard/Android/data/com.fifaskill.trainer/files/input_log.txt` 就能看到完整事件序列，不再依赖实时画面或口头确认。

Purpose: 前三次真机测试都卡在「代理看不到用户按了什么」—— 实时截图只能看到某一帧，用户按完再问「按成功了吗」不可靠。日志把「用户按了什么」变成可回放的事实。
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 输入事件 → 日志文件 | 日志内容只允许输入事件与时间戳，不允许设备序列号或用户数据 |
| 日志写入 → 输入路径 | 日志失败不能影响输入、判定或 UI |
