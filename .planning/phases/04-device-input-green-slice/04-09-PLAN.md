<objective>
把「四步探针 + 校准 + 布局确认」整块替换成一个**单页输入设置**：一屏显示所有轴与按键的实时状态，用户随便推、随便按，页面持续采样；轴对、方向、量程都由用户看着屏幕确认，按 A 保存并直接进入练习。

Purpose: 真机两次失败都证明「分步 + 时间窗口 + 自动判失败」这条路不可用 —— 用户在 1 秒内既看不清提示也做不对动作，B 重来还会因为扳机静止值跳变而永远失败。单页没有时间压力、没有状态切换、没有自动失败，识别错了用户当场就能改。

Output: `InputSetup` 纯逻辑、`input_setup_screen` 一页式界面、组合根切换、无头套件、重建 APK。
</objective>

## 设计（一页，三块）

### 1. 轴表（左上，8 行）

每行：`轴 N  [====----]  -0.12   min -1.00  max 1.00`

- 只读 `PadSampler` 的快照；每帧更新 min/max。
- 正在动的那一行高亮。
- 扳机轴（4/5）单独标 `扳机`，显示 `rest = min`。

### 2. 右摇杆圆点（右上，240×240）

- 用「当前活动轴对」画一个点；十字准星。
- 点下方两行：`轴对：2 / 3（按 LB/RB 换）`、`X：反向（按 X 切换）  Y：正常（按 Y 切换）`。
- 用户推右摇杆时，活动轴对 = 最近 1 秒内 `min(range_x, range_y)` 最大的一对；候选对为 (0,1)、(2,3)、(4,5)、(6,7)。
- 圆点方向必须与手柄一致；不一致就按 X/Y 翻转，直到一致。

### 3. 状态与操作（底部）

- `量程：X -1.00..+1.00 ✓   Y -1.00..+1.00 ✓`（≥1.2 才 ✓；没到就写「还没推到底」）
- `中点：0.01 / -0.02`
- `扳机静止：-1.00 / -1.00`
- 操作：`A 保存并开始` / `B 清空重来` / `X 反转 X` / `Y 反转 Y` / `LB/RB 换轴对`
- 文件末尾一行小字：`设备：<get_joy_name()>`

**没有任何超时、窗口、重试计数、失败屏。** 用户按 A 之前页面一直采样。
