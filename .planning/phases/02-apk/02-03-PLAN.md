新建 `tools/make_font_subset.py`，体例逐条对齐 `tools/sync_config.py`：`#!/usr/bin/env python3`、中文模块 docstring（职责 + 为什么 + 缩进四格的用法示例 + 路径锚定说明）、`from __future__ import annotations`、`typing.List/Optional`（**不用** PEP 585 内建泛型）、只用标准库。

模块级常量：

- `CHAR_SOURCES`：字符来源，按相对仓库根的路径列出 `shared/skills_config.json`（动作名与 `_readme`）、`desktop/padskills/gui.py`（失败建议文案）、`desktop/padskills/detectors.py`（失败短标签）、`mobile/src/smoke/smoke_screen.gd`、`mobile/src/smoke/smoke_screen.tscn`。整文件扫描（取所有非 ASCII 字符），不挑行——这样以后往首屏加一句中文，清单自动跟上。
- `EXTRA_SYMBOLS = "°±→✓✗"`（成功标准 2 写死的五个符号）与 `ASCII_PRINTABLE = "".join(chr(c) for c in range(0x20, 0x7F))`（`%+.3f` 产出的 `+ - . 0-9` 必须在内）。
- `GLYPHS_PATH`、`SC_SUBSET_PATH`、`SYM_SUBSET_PATH`、`OFL_PATH` 四个输出路径常量。
- `SOURCE_URLS`：两个源字体与许可证的官方地址，逐字使用 `https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf`、`https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssymbols2/NotoSansSymbols2-Regular.ttf`、`https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/LICENSE`（三个地址已在本次规划中确认返回 200）。
- `SOURCE_DIR` 默认 `$HOME/.cache/fifa-trainer/fonts`，可用 `--source-dir` 覆盖；源字体不进仓库。

行为：

1. 收集字符：读每个 `CHAR_SOURCES` 文件为 UTF-8，保留 `ord(c) >= 0x80` 的字符；并入 `EXTRA_SYMBOLS` 与 `ASCII_PRINTABLE`；丢弃 `\n`、`\r`、`\t`、空格；按码点排序去重。
2. 写 `required_glyphs.txt`：**一行一个字符**、LF 行尾、无表头（`glyph_coverage.gd` 逐字符读取并跳过换行，写表头会被当成待检查字符）。内容相同就不落盘。
3. 缺源字体时用 `urllib.request` 下载到 `SOURCE_DIR`，打印下载字节数。
4. 调 `subprocess.run(["uv","run","--with","fonttools==4.60.2","pyftsubset", src, "--text-file=" + glyphs, "--output-file=" + out, "--layout-features=*", "--drop-tables+=DSIG"], check=True)` 生成两个子集。**不要 `import fontTools`**：脚本本体保持纯标准库，依赖只出现在这条子进程里。写盘前比较字节，相同则不落盘。
5. 许可证：缺 `SOURCE_DIR/OFL.txt` 时下载上面那个 LICENSE 地址；校验内容含 `SIL OPEN FONT LICENSE`（不含就报错退出，不要静默写一个空文件）；写成 `mobile/assets/fonts/OFL.txt`，不改写、不翻译。
6. `--check` 模式：**只读**。重新推导字符集并与磁盘上的 `required_glyphs.txt` 逐字符比对（差异按「多了 / 少了」两段打印，最多各列 40 个），再断言两个 `.ttf` 存在且非空。任何不一致 `return 1`。`--check` 绝不调用子进程、绝不写盘。
7. 入口契约：`def main(argv: Optional[List[str]] = None) -> int` + `if __name__ == "__main__": raise SystemExit(main())`。

额外要求：`--check` 模式的注释里写清「为什么清单与子集必须同源」——清单被手改而子集没重裁时，字形闸门会对着自己生成的清单报绿，而屏幕上依然豆腐；这是本仓库第二次出现同构的假绿风险（第一次在 `tools/check_desktop.sh` 的配置校验）。
