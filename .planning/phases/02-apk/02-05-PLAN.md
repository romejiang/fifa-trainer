新建 `mobile/tools/verify_clean_export.sh`，体例照 `tools/verify_clean_clone.sh`：文件头写清「只验证已提交状态」「本脚本不复制任何检查逻辑」，入口用 `exit 2` 拒绝脏工作区（脏树里 clone 出来的是旧代码，那样的绿没有意义）。

**入口守卫只判已跟踪文件**：`git -C "$repo_root" status --porcelain --untracked-files=no` 非空时打印理由并 `exit 2`。文件头必须把这条理由写出来，否则下一个人会以为守卫漏了未跟踪文件——事实相反：`git clone` 只复制提交，未跟踪文件根本不进 clone，它们只会让 clone 里的闸门**失败**（文件不存在），不可能让它假绿。真正会让「绿」失去意义的，是已跟踪文件与 `HEAD` 不一致：那才是「clone 里跑的是旧代码」。顺带一个实际收益：用户自己的未跟踪在制品（例如 `design/`）不该把一个与它无关的重导出闸门挡在门外。

流程四步：`git clone --quiet "$repo_root" "$tmp/clone"` → `cd "$tmp/clone"` → `bash mobile/tools/gate-b.sh` → `git status --porcelain` 必须为空。收尾打印 `✓ 干净 clone 重导出成功：闸门 B 全绿，工作区无漂移`。

在 `git clone` 之后、跑闸门 B 之前，先断言五个 Godot 边车在 clone 里是**已跟踪**文件：用 `git -C "$tmp/clone" ls-files --error-unmatch` 逐个点名 `mobile/src/smoke/smoke_screen.gd.uid`、`mobile/tools/check_pack.gd.uid`、`mobile/tools/glyph_coverage.gd.uid`、`mobile/assets/fonts/NotoSansSC-Subset.ttf.import`、`mobile/assets/fonts/NotoSansSymbols2-Subset.ttf.import`。它们不是可有可无的缓存：`.import` 钉住导入参数与目标路径，`.uid` 钉住脚本 UID。先断言的好处是失败信息直指「上游漏提交」——否则闸门 B 跑完后只会以一条 `?? …/*.import` 的形式含糊报错，下一个人多半会去改 `.gitignore` 而不是补提交。

注意 clone 内部那一句 `git status --porcelain` **保持全量**（含未跟踪），与入口守卫的范围不同：clone 起始是干净的，`gate-b.sh` 跑完如果冒出任何一条路径，说明 `.gitignore` 漏了东西，或者有 Godot 边车没提交（`*.import` / `*.uid` 会以 `??` 出现）——那正是这条零漂移断言要抓的东西。这句话也要写进注释，两个 `--untracked-files` 语义不同是有意的。

文件头还要写一句环境继承：本脚本不导出任何签名变量，`GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD` 必须在**调用前**就存在于 shell 里（它是闸门 B 唯一的必填输入，路径与别名由 gate-b 自己解析默认值），否则 clone 里的闸门 B 会在第一步守卫处就停，而失败原因看起来像「仓库状态不够」——那会误导人。
