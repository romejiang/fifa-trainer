`mobile/src/core/config/overlay_merge.gd`：`class_name OverlayMerge` + `extends RefCounted`。`const SCHEMA_VERSION := 1`；`const ALLOWED_KEYS := [&"enabled", &"required_button", &"button_mode"]`。`static func merge(base: Dictionary, overlay: Dictionary, current_base_sha256: String) -> OverlayResult` 按顺序：
1. `result.data = base.duplicate(true)`——**绝不修改调用者的 base**（回放测试会复用同一份 base）。
2. `schema_version` 不是 `TYPE_INT` / `TYPE_FLOAT` → `_discard(&"overlay_schema_invalid", "自定义设置缺少有效的 schema_version，已恢复默认。")`；`int(schema) > SCHEMA_VERSION` → `_discard(&"overlay_schema_too_new", "自定义设置来自更新的版本，已恢复默认。")`（未来版本写的文件，当前版本不猜）。
3. `base_sha256` 不是 `TYPE_STRING`，或 `String(hash).to_lower() != current_base_sha256.to_lower()` → `_discard(&"overlay_base_changed", "配置已更新，已丢弃自定义按键设置。")`——**整体丢弃**，不做部分保留。
4. `skills` 不是 `TYPE_DICTIONARY` → `_discard(&"overlay_schema_invalid", ...)`。
5. 先用 base 的 `skills` 建 `name -> 该 skill 字典` 的索引（只对 `TYPE_DICTIONARY` 且含 `name` 的项）；遍历 overlay 的 `skills`：名字不在索引里 → `warnings.append` 一条 `overlay_skill_unknown`（`severity` 用 `ConfigError.SEVERITY_WARNING`），忽略该条；值不是字典 → 忽略；逐键检查 `StringName(key) in ALLOWED_KEYS`，不在 → `overlay_key_unknown` warning 并忽略该键，在则写进 `data` 里那份 skill 字典并把 `applied` 置真。
注意：overlay 的键来自 JSON，是 `String`；`ALLOWED_KEYS` 是 `StringName`。本机实测两者作为字典键可互换、`StringName(key) not in ALLOWED_KEYS` 正常工作，不要为此写一套手工转换表。
