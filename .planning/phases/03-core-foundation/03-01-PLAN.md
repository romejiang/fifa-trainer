`mobile/src/core/geometry.gd`：`class_name Geometry` 后接 `extends RefCounted`（顺序按官方 style guide），文件顶部写中文 `##` 契约说明——0° = 上、90° = 右、180° = 下、270° = 左、范围 `[0, 360)`、角度增大 = 屏幕顺时针、手柄原始坐标 x 向右 y 向下且只在本文件的 `angle_of` 里换算一次。五个 static 函数：`norm_deg(angle: float) -> float` 用 `fposmod(angle, 360.0)`（**不要**用 `%`：GDScript 对两个 float 使用 `%` 是解析错误；也**不要**用 `fmod`：它保留负号，会让「左」变成 -90°）；`signed_delta(a_from: float, a_to: float) -> float` 用 `fposmod(a_to - a_from + 180.0, 360.0) - 180.0` 并在注释里写明真实区间是 `[-180, 180)`、`signed_delta(0, 180)` 返回 -180、**不得**为了迎合 Python 那边写错的文档字符串而改成 +180；`angle_diff(a: float, b: float) -> float` 用 `absf(signed_delta(a, b))`；`angle_of(x: float, y: float) -> float` 先做居中守卫 `if x == 0.0 and y == 0.0: return 0.0`（该守卫同时覆盖 -0.0，没有它 `atan2(0.0, -0.0)` 会返回 180°，界面上会显示「正后方」），再 `return norm_deg(rad_to_deg(atan2(x, -y)))`——参数顺序仍是 y 在前、x 在后，公式文本恰好是 `atan2(x, -y)`，**不要**改写成 `atan2(-y, x)`；`magnitude(x: float, y: float) -> float` 用 `sqrt(x * x + y * y)`。缩进用 Tab，函数之间两个空行，标识符全英文 ASCII、注释与文档字符串中文。
