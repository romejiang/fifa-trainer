## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 开发者 CLI（`--write-config`）→ 配置文件 | 这是唯一能把内容写进「真源」或「副本」的入口；路由错了就会制造第二真源或改坏冻结态 |
| `.gitignore` → 版本控制内容 | 一条规则就能让打包脚本或配置副本从仓库里消失，而且本地完全无声 |
| 生成副本 → 运行时读取 | `.gitignore` 与副本存在性共同决定干净 clone 上跑的是真源还是 `DEFAULT_CONFIG` |
