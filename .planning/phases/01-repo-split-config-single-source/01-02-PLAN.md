    **sync_config.py 的公开契约：**
    - 常量 `SOURCE = Path("shared") / "skills_config.json"`；`TARGETS` 是二元组 `(Path("desktop") / "skills_config.json", Path("mobile") / "assets" / "config" / "skills_config.json")`；`SIDECAR_SUFFIX = ".sha256"`；`_SKIP_DIRS` 是扫描时要跳过的目录名集合：`.git`、`.venv`、`.planning`、`__pycache__`、`node_modules`、`.godot`、`build`、`dist`、`export`。
    - `repo_root() -> Path`：`Path(__file__).resolve().parent.parent`（以脚本位置为锚，绝不依赖 cwd）。
    - `sha256(data: bytes) -> str`：`hashlib.sha256(data).hexdigest()`。不得自实现摘要、不得调用 `shasum`。
    - `sidecar(path: Path) -> Path`：同目录下 `path.name + ".sha256"`。
    - `find_stray_copies(root: Path) -> List[Path]`：`root.rglob("skills_config*.json")`，跳过 `_SKIP_DIRS` 命中的路径段，返回不在「SOURCE + TARGETS」白名单里的路径（排序后返回）。
    - `sync(root: Path, stream: Optional[TextIO] = None) -> int`：读真源 bytes；源缺失时打印中文 `✗ 缺少真源 …` 返回 1；对每个目标：`mkdir(parents=True, exist_ok=True)`，仅当内容不同才 `write_bytes`（保证重复运行不产生 diff），`.sha256` 内容固定为 `f"{digest}  {target.name}\n"`，仅当不同才写；每个目标打印 `✓ <相对路径>`；返回 0。
    - `check(root: Path, stream: Optional[TextIO] = None) -> int`：**先收集全部问题再一次性报告**（不在第一个错误处中断），问题清单至少覆盖：真源缺失；副本不存在；副本与真源逐字节不等；`.sha256` 缺失；`.sha256` 里的第一个字段与真源摘要不符；存在多余副本（`find_stray_copies` 非空，报出每个路径）。每条打印中文 `✗ …` 到 stream（默认 `sys.stderr`），有任一问题返回 1，否则返回 0。
    - `main(argv: Optional[List[str]] = None) -> int`：`--check` 布尔开关、`--root` 可选路径（默认 `repo_root()`；用 `Path(args.root).resolve()`，不是目录就 `raise SystemExit` 中文报错）。返回 0 / 1。
