    模块头照抄项目三件套：`#!/usr/bin/env python3`、中文模块 docstring（一句话职责 + 一句「为什么不解析 stdout」的理由）、`from __future__ import annotations`。导入只用标准库：`argparse`、`importlib.util`、`sys`、`pathlib.Path`、`typing.List`、`typing.Optional`。类型标注一律 `typing` 泛型（`Optional[List[str]]`），禁止 PEP 585 的 `list[str]`。

    CLI 对齐 `main.py` 的形状：函数签名 `main(argv: Optional[List[str]] = None) -> int`，`argparse.ArgumentParser(prog="collect_checks.py", description=...)` 用中文，位置参数 `test_script`，`--out` 必须 `required=True`。

    实现顺序（每一步都有原因，别改）：
    1. `path = Path(args.test_script).resolve()` —— 先绝对化，后续写文件与日志都用它。
    2. `spec = importlib.util.spec_from_file_location(f"_collect_{path.stem}", path)`，`mod = importlib.util.module_from_spec(spec)`，先 `sys.modules[spec.name] = mod` 再 `spec.loader.exec_module(mod)`。必须先 exec 再替换，因为两个测试脚本都在模块级定义 `check`；`tests/` 不是包，不能用 `import tests.xxx`。
    3. `original = mod.check`；定义 `def recording_check(label, ok, extra="", *rest, **kwargs):`，先 `names.append(label)`，再 `return original(label, ok, extra, *rest, **kwargs)`。保留对原函数的调用，这样 PASS/FAIL 统计与彩色输出照常发生，测试文件本身零改动。
    4. `mod.check = recording_check`，然后 `try: rc = mod.main()`，在 `finally` 里写文件：`Path(args.out).write_text("".join(f"{path.name}\t{n}\n" for n in names), encoding="utf-8")`。写文件必须显式 `encoding="utf-8"`，不依赖 locale。
    5. `return rc`。

    禁止事项：不得解析 stdout（ANSI 颜色码、locale 编码、`extra` 里的运行时数值三重不确定）；不得修改 `tests/` 下任何文件；不得给 `tools/` 脚本加 `__all__`（项目只要求 `padskills/*` 声明）；不得用 `%` 或 `.format()` 拼字符串，只用 f-string。
