<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 源仓库工作区 → clone | clone 只反映已提交状态；脏工作区会让验证对象与当前代码不一致 |
| clone → 闸门结论 | 若 clone 里缺配置副本或忽略规则写错，230 项可能假绿或无法复现 |
| 反例 → 结论 | 一个永远打印成功的反例比没有反例更危险：它把「闸门有效」变成一句未经检验的断言 |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-14 | Repudiation | `--tamper` 反例 | high | mitigate | 反例必须同时满足：`--check` 非零、输出含被改文件路径、闸门非零、还原后重新变绿；禁止 `|| true` 吞退出码；任一条不成立即 exit 1 |
